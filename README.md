# 📝 Personal Notes App (React.js)

Aplikasi catatan pribadi sederhana yang dibangun menggunakan **React.js (Class Components)**. Aplikasi ini memungkinkan pengguna untuk membuat, membaca, menghapus, mengarsip, serta mencari catatan berdasarkan kata kunci secara interaktif.

---

## 🚀 Fitur Utama

- **Tambah Catatan Baru**: Menambahkan catatan dengan judul (maksimal 50 karakter) dan isi catatan (minimal 10 karakter).
- **Indikator Sisa Karakter**: Menampilkan jumlah sisa karakter secara dinamis saat mengetik judul catatan.
- **Validasi Form**: Menampilkan pesan peringatan jika isi catatan kurang dari 10 karakter saat disubmit.
- **Pengelompokan Catatan**: Catatan dikelompokkan secara otomatis berdasarkan bulan dan tahun pembuatan (*Month Year Grouping*).
- **Kategori Aktif & Arsip**: Memisahkan daftar antara *Catatan Aktif* dan *Arsip* dengan fitur *toggle archive*.
- **Pencarian Catatan**: Fitur pencarian catatan secara *real-time* berbasis *case-insensitive*.
- **Hapus Catatan**: Menghapus catatan dari daftar secara permanen.

---

## 🛠️ Teknologi yang Digunakan

- **React.js** (State Management & Component Architecture)
- **CSS3** (Styling & CSS Grid Layout)
- **JavaScript (ES6+)**
